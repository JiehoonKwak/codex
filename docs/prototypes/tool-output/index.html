현재 가능한 방법과 다른 harness 비교

현재 설치 버전은 0.163.0입니다. 로컬 설정은 tui.fullscreen_transcript = false였습니다. 이 버전의 새 전체 화면 transcript에는 짧은 툴 미리보기와 개별 펼치기가 이미 있습니다. 아래 명령은 저장된 설정을 바꾸지 않고 한 번 시험하는 방법입니다.

codex -c tui.fullscreen_transcript=true

F4로 툴 활동에 포커스를 옮기고, ↑↓로 이동한 뒤 Enter 또는 ←→로 접고 펼칠 수 있습니다. 이것은 고정 길이 미리보기이며, 이 프로토타입의 Low / Medium / Full 설정은 아직 제안입니다. 기존 compact 렌더링 구현
